## 1. Границы MVP
В первой версии поддерживаем:
- Устройство может одновременно искать соседей и рекламировать себя.
- Каждое устройство поднимает GATT Server; для исходящего подключения оно также использует GATT Client.
- В первой версии поддерживаем максимум одного peer (соединение) на устройство.
- Стабильный peerId определяет инициатора подключения, чтобы устройства не создавали параллельные подключения друг к другу (В одинаковых ролях).
- После соединения стороны обмениваются HELLO, сообщениями DATA и подтверждениями ACK.
- Непрерывная фоновая сессия запускается пользователем из открытого приложения и поддерживается сервисом с уведомлением.
- После уничтожения процесса нельзя считать BLE-соединение сохранённым: восстановление соединения рассматриваем как отдельную операцию.

В MVP не входят relay через третье устройство, маршрутизация, store-and-forward, криптографический обмен ключами и совместимость со спецификацией Bluetooth Mesh. Их добавление потребует отдельного дизайна протокола.
